# Brand Guide — Custom Learn to Read

One brand across site, emails, flipbook, and printed books.

## Palette

| Token | Hex | Use |
|---|---|---|
| Cream | `#FFF8ED` | backgrounds, book pages, text band tint |
| Ink | `#2F2A24` | primary text, darkest illustration accent |
| Ink soft | `#6B6257` | secondary text, page numbers |
| Peach | `#F5B78D` | primary accent, buttons, spine, dividers |
| Gold | `#F7D58B` | secondary accent |
| Sage | `#B8C8AD` | tertiary accent |
| Sky (books only) | `#A9C7E4` | illustration palette |
| Terracotta (books only) | `#D98A5F` | illustration palette |

No neon, no pure black, no cool grays.

## Typography

- **Display/serif:** Fraunces (web); Georgia fallback — used for titles ("The End", cover/title pages).
- **Body/sans:** Inter; system-ui fallback — used for reading text in books (big, bold, high-contrast for early readers), UI, emails.
- Book reading text: Inter 700, ink on the cream text band. Page numbers: Inter 600, ink-soft.

## Book interior conventions

- Text band: bottom 20% of trim (16% on cover), cream at 97% opacity over full-bleed art.
- Cover title set in serif; interior pages in sans.
- Every book ends with "The End" + "You did it, {Name}!", a "Words I can read" page, and (print) "My drawing" pages.

## Voice

Warm, encouraging, family-made. The child is always the hero. Never scary, never brands/franchises. Sign-offs: "Happy reading! — The Custom Learn to Read family."
